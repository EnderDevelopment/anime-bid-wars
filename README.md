# Anime Bid Wars

Anime Bid Wars is a competitive Roblox game combining anime character auctions, strategic team building, and automatic battles. Two players compete at an auction table to win powerful anime characters through bidding. Each starts with a limited amount of coins and can collect a maximum of 6 characters. The auction ends when both players have 6 characters or run out of coins. After the auction, both players' teams automatically battle, and the player with the stronger team wins.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the scripts in the specified locations in Roblox Studio:
   - `AuctionSystem.lua` in ServerScriptService
   - `BattleSystem.lua` in ServerScriptService
   - `GameManager.lua` in ServerScriptService

## Use

1. Place the scripts in the specified locations in Roblox Studio.
2. Customize the game parameters as needed.
3. Run the game and enjoy the Anime Bid Wars experience!
